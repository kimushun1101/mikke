# リンク集

見出しだけのノート [[no-frontmatter|FM無し]] と、fragment 付きの [[filename-title#由来]] を張る。
パス形式の [[notes/short.md]] と、どのノートにも解決できない [[missing-note]] も並べておく。
自ノート内アンカー [[#規則]] はリンク先の対象にならない。

## 規則

リンク先の解決はパス成分の末尾一致で行い、曖昧な場合は候補を全件表示する。
